#  Sistema de Controle de Elenco de Voleibol - v1.1

##  Melhorias da versão

Nesta versão foram adicionadas melhorias na organização do código e validações para tornar o sistema mais seguro e fácil de manter.

### Novidades:

- ✅ Código reorganizado utilizando funções separadas
- ✅ Validação de nome (sem números e tamanho mínimo)
- ✅ Validação de CPF
- ✅ Validação de idade
- ✅ Validação de altura
- ✅ Validação de peso
- ✅ Validação da posição do atleta
- ✅ Melhor organização das operações CRUD
- ✅ Correção de problemas relacionados à entrada de dados

###  Objetivo da atualização

Melhorar a estrutura do projeto, aumentar a confiabilidade dos cadastros e preparar o sistema para futuras funcionalidades.
